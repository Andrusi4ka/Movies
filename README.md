### Spread-оператор та Rest-оператор

#### Spread-оператор (...)

**Spread-оператор (...)** дозволяє розгорнути елементи ітерабельних об'єктів (наприклад, масивів) або властивості об'єктів у місцях, де очікується декілька аргументів (у викликах функцій) або декілька елементів (в літералах масивів) чи ключ-значення (в літералах об'єктів).

**Spread з масивами**

Spread-оператор можна використовувати для копіювання або об'єднання масивів без необхідності використання методів concat() або циклів.

Приклад коду:

```js
const firstArray = [1, 2, 3];
const secondArray = [4, 5, 6];
// Об'єднання масивів
const combinedArray = [...firstArray, ...secondArray];
console.log(combinedArray); // Виведе: [1, 2, 3, 4, 5, 6]
```

**Spread з об'єктами**

Spread-оператор також застосовний до об'єктів для копіювання або об'єднання їх властивостей у новий об'єкт.

Приклад коду:

```js
const firstObject = { name: 'John' };
const secondObject = { age: 30 };
// Об'єднання об'єктів
const combinedObject = { ...firstObject, ...secondObject };
console.log(combinedObject); // Виведе: { name: 'John', age: 30 }
```

**Spread з функціями**

Spread-оператор може використовуватися для передачі елементів масиву в функцію як окремі аргументи.

Приклад коду:

```js
function sum(a, b, c) {
  return a + b + c;
}
const numbers = [1, 2, 3];
// Передача елементів масиву як аргументів
console.log(sum(...numbers)); // Виведе: 6
```

В кожному з цих прикладів spread-оператор (...) спрощує роботу з даними, дозволяючи легко копіювати та об'єднувати масиви та об'єкти, а також передавати елементи масиву в функції як окремі аргументи.

#### Rest-оператор (...)

**Rest-оператор (...)** в JavaScript дозволяє збирати необмежену кількість аргументів або елементів у масив. Використовується в оголошенні функцій для збирання залишкових аргументів або в деструктуризації об'єктів і масивів.

**Rest з масивами**

Rest-оператор дозволяє вилучити частину елементів масиву, поміщаючи їх в новий масив, що спрощує роботу з підмножинами масивів.

Приклад коду:

```js
const numbers = [1, 2, 3, 4, 5];
const [first, second, ...rest] = numbers;
console.log(first); // Виведе: 1
console.log(second); // Виведе: 2
console.log(rest); // Виведе: [3, 4, 5]
```

**Rest з об'єктами**

Хоча rest-оператор частіше асоціюється з масивами, його також можна використовувати для створення нового об'єкта з деякими властивостями іншого об'єкта.

Приклад коду:

```js
const person = { name: 'John', age: 30, city: 'New York' };
const { name, ...rest } = person;
console.log(name); // Виведе: John
console.log(rest); // Виведе: { age: 30, city: 'New York' }
```

**Rest з функціями**

Rest-оператор може бути використаний у визначенні функції для збору будь-якої кількості аргументів у масив, дозволяючи функції приймати необмежену кількість параметрів.

Приклад коду:

```js
function sum(...numbers) {
  return numbers.reduce((acc, current) => acc + current, 0);
}
console.log(sum(1, 2, 3, 4, 5)); // Виведе: 15
```

У кожному з цих прикладів rest-оператор (...) використовується для зручної роботи з даними, дозволяючи легко вилучати підмножини масивів та об'єктів, а також збирати аргументи функцій у масиви.

### Destructuring Assignment (Деструктуроване присвоєння, Деструктуризація)

**Деструктуризація масиву**

Деструктуризація масиву дозволяє присвоювати елементи масиву до змінних у одному рядку коду, що спрощує доступ до елементів масиву.

Приклад коду:

```js
const colors = ['червоний', 'зелений', 'синій'];
const [red, green, blue] = colors;
console.log(red); // Виведе: "червоний"
console.log(green); // Виведе: "зелений"
console.log(blue); // Виведе: "синій"
```

**Деструктуризація об'єкта**

Деструктуризація об'єкта дозволяє присвоювати властивості об'єкту до змінних з аналогічними назвами.

Приклад коду:

```js
const student = { name: 'Alex', age: 22 };
const { name, age } = student;
console.log(name); // Виведе: "Alex"
console.log(age); // Виведе: 22
```

**Деструктуризація параметрів функції**

Деструктуризація параметрів функції дозволяє безпосередньо в параметрах функції виділити властивості об'єкта, які потім можна використовувати в тілі функції.

Приклад коду:

```js
function displayStudentInfo({ name, age }) {
  console.log(`Name: ${name}, Age: ${age}`);
}
displayStudentInfo({ name: 'Alex', age: 22 });
// Виведе: "Name: Alex, Age: 22"
```

У кожному з цих прикладів деструктуризація полегшує роботу з даними, дозволяючи більш ефективно отримувати доступ до значень масивів та об'єктів, а також спрощує обробку параметрів функцій.

### Generators & Symbol iterators

Генератори в JavaScript — це спеціальні функції, які дозволяють призупиняти та відновлювати виконання коду. Вони забезпечують гнучке управління потоком виконання і використовуються для створення ітерованих послідовностей даних за допомогою ключових слів function* для оголошення та yield для вироблення послідовності значень.

Приклад коду:

```js
function* numberGenerator() {
  yield 1;
  yield 2;
  yield 3;
}

const gen = numberGenerator(); // Ініціалізація генератора

console.log(gen.next().value); // Виведе: 1
console.log(gen.next().value); // Виведе: 2
console.log(gen.next().value); // Виведе: 3
```

У цьому прикладі:

 - Оголошено генераторну функцію `numberGenerator` за допомогою `function*`, яка виробляє (yield) три числа: 1, 2, та 3.
 - Створено інстанс генератора `gen` викликом `numberGenerator()`.
 - Метод `gen.next()` викликається для отримання наступного значення з генератора. Кожен виклик `next()` повертає об'єкт, що містить властивості `value` (значення вироблене генератором) та `done` (булеве значення, що вказує, чи генератор завершив вироблення значень).

Генератори використовуються для легкого створення ітерованих послідовностей, керування асинхронним кодом, реалізації шаблонів проєктування, таких як корутини, та багато іншого.

**Symbol iterators**

**Символ ітератора** (`Symbol.iterator`) в JavaScript — це вбудований символ, який використовується для визначення стандартного ітератора для об'єкта. Об'єкт вважається ітерованим, якщо він реалізує метод, доступний через `Symbol.iterator`, який повертає об'єкт із методом `next()`. Цей механізм дозволяє об'єктам визначати, як їх можна ітерувати в циклі `for...of`.

Для демонстрації застосування ітератора до неітерованого об'єкта, розглянемо приклад, де ми створимо простий об'єкт, який за замовчуванням не є ітерованим, та надамо йому можливість ітерації через `Symbol.iterator`.

Приклад коду:

```js
const nonIterableObject = {
  a: 1,
  b: 2,
  c: 3
};

nonIterableObject[Symbol.iterator] = function() {
  const keys = Object.keys(this);
  let index = 0;
  return {
    next: () => {
      if (index < keys.length) {
        return { value: this[keys[index++]], done: false };
      } else {
        return { done: true };
      }
    }
  };
};

for (const value of nonIterableObject) {
  console.log(value); // Виведе по черзі: 1, 2, 3
}
```

У цьому прикладі:

 - Створено об'єкт `nonIterableObject`, який містить три властивості (`a`, `b`, `c`) і за замовчуванням не має ітераційних можливостей.
 - Додаємо метод `Symbol.iterator` до `nonIterableObject`, який робить об'єкт ітерованим. Цей метод повертає ітератор, визначений через внутрішню функцію з методом `next`.
 - Метод `next` ітерує ключі об'єкта, повертаючи значення кожної властивості до тих пір, поки не будуть ітеровані всі ключі, після чого вказує на завершення ітерації через `{ done: true }`.
 - Використовуючи цикл `for...of`, можемо ітерувати через `nonIterableObject`, як ніби це звичайний ітерований об'єкт, виводячи значення його властивостей.
Цей приклад показує, як можна додати ітераційну поведінку до будь-якого об'єкта в JavaScript, використовуючи `Symbol.iterator`.

### Оператор необов’язкового ланцюжка (?.) / Optional chaining operator

Оператор необов'язкового ланцюжка (?.) дозволяє нам безпечно отримувати доступ до властивостей об'єкта, які можуть не існувати. Цей оператор зупиняє подальше виконання ланцюжка, якщо частина перед ним виявляється undefined або null, тим самим уникаючи помилок при спробі доступу до властивостей цих значень.

Приклад коду:

Розглянемо об'єкт `user`, який може мати властивість `address`, але це не гарантовано:

```js
const user = {
    name: 'Олексій',
    address: { street: 'Шевченка', city: 'Львів' }
};

// Традиційний спосіб отримання вулиці з адреси користувача
const street = user && user.address ? user.address.street : 'Вулиця не вказана';

// Використання оператора необов'язкового ланцюжка
const safeStreet = user?.address?.street ?? 'Вулиця не вказана';

console.log(street); // 'Шевченка'
console.log(safeStreet); // 'Шевченка'
```

У цьому прикладі, якщо `user` або `user.address` є `null` або `undefined`, `safeStreet` одразу ж отримає значення 'Вулиця не вказана', уникаючи помилки типу "Cannot read property 'street' of undefined".
